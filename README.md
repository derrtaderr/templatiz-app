# Templatiz App

A modern content management and creation platform built with Next.js 14, featuring an intuitive dashboard, content scheduling, and analytics.

## Features

- 📊 Interactive Dashboard with Real-time Analytics
- 📝 Content Creation and Management
- 📅 Content Calendar and Scheduling
- 📈 Performance Insights with Charts
- 🎯 Smart Content Workflow
- 🎥 Video Studio Integration
- 🎙️ Voice Setup and Management
- 🏆 Rewards System
- 📱 Responsive Design

## Tech Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **UI Components:** Radix UI
- **Charts:** Recharts
- **State Management:** React Hooks
- **Icons:** Lucide Icons

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/derrtaderr/templatiz-app.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
